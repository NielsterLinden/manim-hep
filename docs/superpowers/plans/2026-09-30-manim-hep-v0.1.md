# manim-hep v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build manim-hep v0.1 as the spec describes: the thin core package and CLI (M1), the agent layer (M2), the 14-example starter gallery (M3), and the docs and release tooling (M4). Everything short of the outward-facing release steps.

**Architecture:** One repo, three layers (spec D4).
- `src/manim_hep` is a small, tested package on ManimCE 0.21.
- `plugin/` holds the portable Agent Skills and the Claude agents. The wheel also bundles the skills, so `manim-hep init --agent codex` can copy them into a user project.
- `gallery/` holds self-contained examples on synthetic data, rendered in CI.

**Tech Stack:**
- Python ≥ 3.11 and ManimCE 0.21 (cairo renderer).
- NumPy, Pillow and PyAV, which are already Manim dependencies.
- hatchling, pytest, ruff.
- MkDocs Material and mkdocstrings.
- GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-30-manim-hep-design.md`

**Execution note (2026-09-30).** The owner approved the spec and asked for "full speed". This plan is executed natively in the planning session, with one whole-branch review at the end. The tasks pin files, interfaces and tests; the implementation code lives in the commits and is not duplicated here. Wherever the plan and the spec disagree, the spec wins.

## Global Constraints

**Versions and dependencies**
- Python `>=3.11`; `manim>=0.21,<0.22`.
- No runtime dependency beyond Manim's own. Optional extras: `[mplhep]` and `[dev]`.

**Names**
- PyPI `manim-hep`, import `manim_hep`, CLI `manim-hep`.
- Plugin `manim-hep@manim-hep`, display name "Agentic Manim for HEP".
- Repository `github.com/NielsterLinden/manim-hep`.

**Content rules**
- MIT everywhere. No collaboration logos, no private paths or hostnames, no personal names except the owner's, and synthetic data only in the gallery.

**API rules**
- `manim_hep.palette` never imports Manim.
- The public API is add-only.
- Plugin version = package version = `0.1.0`.
- `experiments.label()` takes `status` as a required keyword argument with no default.

**Checks**
- Clips end on `self.wait(t)` with t ≤ 0.2 s.
- Title band: y > 2.7, which is the top 1.3/8 of the frame. Ink means a pixel whose grey value differs from the background by more than 30. `render` warns when more than 0.1 % of the band is ink.
- Seam, judged at 1920×1080:
  - a pixel counts as different when its max over RGB of |Δ| is above 24;
  - fail when the mean is above 1.0, when more than 0.5 % of pixels differ, or when there are more than 50 blobs (fully-over 5×5 windows).

**Publication**
- The README starts with a one-line work-in-progress note until v0.1.0.
- No push, GitHub repo creation, PyPI upload, issue creation or directory submission without the owner's explicit go-ahead.

## Review Focus

1. **A user repo already has `AGENTS.md`, `CLAUDE.md`, `.gitignore` or `.claude/settings.json`** with foreign content, CRLF line endings or a half-deleted marker block. `init` must leave everything outside its markers byte-identical, keep CRLF, and write `<file>.manim-hep.new` instead of guessing (Task 17 tests: CRLF round trip; start marker without end marker).
2. **Paths with spaces and non-ASCII characters**, as in Windows home folders and this repo's own folder name. `render`, `seam`, `init` and `lint` must work there (Tasks 11–13 and 17 run their tests in a temporary folder named `with space é`).
3. **Manim fails** (syntax error, unknown scene, missing LaTeX). `render` must exit non-zero, show the log tail, and never report an MP4 left over from an earlier render (Task 12: failing scene → exit 1, no frames, stale MP4 ignored).
4. **`seam` gets 480p15 drafts or mismatched sizes.** Frames are resized to 1080p before judging; a different aspect ratio is a clear error, not a crash (Task 11).
5. **`label()` gets a status in the wrong case** ("preliminary") or another experiment's status ("Unofficial" for CMS). It raises a `ValueError` that lists the valid statuses (Task 5).

### Task 10: `detector`

**Files:** Create `src/manim_hep/detector.py`, `tests/test_detector.py`.

**Interfaces**
- `DEFAULT_RADII = {"beam_pipe": (0, .12), "tracker": (.2, 1.0), "solenoid": (1.05, 1.12), "ecal": (1.2, 1.65), "hcal": (1.75, 2.35), "muon": (2.5, 3.0)}`.
- `BarrelSlice(radii=None, *, center=ORIGIN)`.
  - It merges the given radii with the defaults and validates them: inner < outer, and no overlaps.
  - `.layers` is a dict ordered inside-out; `.radius(name) -> (inner, outer)`.
- `track(pt, charge, field, *, phi=0.0, r_max=1.0, origin=ORIGIN, scale=1.0, color=None)`. `pt` is in GeV, `field` in T, and `scale` in units per metre.
  - Radius: R = pt / (0.2998 · |q| · |B|).
  - B > 0 points out of the screen, so a positive charge bends clockwise.
  - A neutral particle or a zero field gives a straight line.
  - The track stops at `r_max`, or after a full turn.
- `signature(kind, detector, *, phi=0.0, charge=-1, pt=None)`.
  - `kind` is one of `electron`, `muon`, `photon`, `jet`, `tau1`, `tau3`, `neutrino`.
  - The result is a VGroup with `.tracks`, `.deposits` and `.hits`.

- [ ] Tests:
  - radii defaults, merging, and overlap errors;
  - layer order;
  - curvature sign for q = +1 and phi = 0, with B > 0 (end y < 0) and B < 0 (end y > 0);
  - the radius scales with pt;
  - straight tracks for a neutral particle and a zero field;
  - tracks stop at `r_max`;
  - per kind:
    - the muon reaches the muon radius;
    - the electron ends at the ECAL;
    - the photon has no solid track;
    - the neutrino extends beyond the outer radius;
    - the jet has at least 3 tracks and deposits in both calorimeters;
    - `tau1`/`tau3` have 1 and 3 tracks;
  - an unknown kind raises.
- [ ] Implement; run the tests; commit.

### Task 12: `render`

**Files:** Create `src/manim_hep/cli/render.py`, `tests/test_render.py` (marked `render`).

**Interfaces:**
- `render FILE SCENE [--final] [--frames T1,T2] [--slug S]`.
  - The project root is where `manim-hep.toml` lives, else the working directory.
  - Scratch output goes to `.manim-hep/work/<slug>/`.
  - A cross-platform lock at `.manim-hep/render.lock` (msvcrt on Windows, fcntl elsewhere) keeps renders serial.
  - Manim runs as `python -m manim render --quality l|h --media_dir … -o <slug>`.
  - The MP4 is located by modification time after the start of this render, so stale files are ignored.
  - `first`, `last` and the requested times are written as PNGs.
  - The title band and keep-out areas are checked on the last frame.
- `--final` delivers `<root>/clips/<slug>_vK.mp4` and `_vK_final.png`, with K the next free version; nothing is ever overwritten.
- The slug defaults to the kebab-cased scene name.

- [ ] Tests:
  - a Square scene renders, exits 0, and writes the PNGs;
  - a syntax error exits 1, writes no PNGs, and shows the log tail;
  - `--final` twice gives `v1` and then `v2`;

### Task 13: `lint`

**Files:** Create `src/manim_hep/cli/lint.py`, `tests/test_lint.py`.

**Interfaces:**
- `lint_source(src, path) -> list[Finding(path, line, code, message)]`.
- `onscreen_strings(src) -> list[(line, text)]`.
- `run(paths) -> int`. It exits 1 on any finding and always prints the on-screen strings.

**Codes**

| Code | Flags |
|---|---|
| MH001 | Hard-coded colour: a hex literal, a Manim colour constant, or `ManimColor(`/`rgb_to_color(` with a literal |
| MH002 | A literal `font=` |
| MH003 | `manimlib`, or a ManimGL-only name (`ShowCreation`, `InteractiveScene`, `TexText`, `OldTex`, `OldTexText`, a `CONFIG` class attribute, `.embed()`) |
| MH004 | `construct` does not end with `self.wait(t)` with t ≤ 0.2 |
| MH005 | A hand-typed experiment label (`ATLAS\|CMS\|LHCb` followed by a status word) |
| MH006 | A private-path pattern (`/afs/`, `/eos/`, `/project/`, `/data/…/users/`, `X:\Users\`, `/home/<name>`, `/Users/<name>`, lxplus/lxbatch/stbc hostnames) |

A `# noqa: MHxxx` comment on the line suppresses the finding.

- [ ] Tests: one positive and one negative case per code; noqa; the on-screen strings list; exit codes.
- [ ] Implement; run the tests; commit.
